# 💧 Reto Gota a Gota

## 🎮 Descripción

**Reto Gota a Gota** es un videojuego educativo e interactivo en el que el jugador debe tomar decisiones rápidas para **ahorrar agua**.

El juego presenta diferentes situaciones relacionadas con el uso del agua y propone al jugador elegir la mejor respuesta en poco tiempo. Cada decisión correcta permite avanzar en el reto y representar una cantidad de agua ahorrada.

El objetivo es aprender sobre el cuidado del agua mientras se intenta conseguir la mayor puntuación posible.

## 🎯 Objetivo del jugador

Tomar decisiones correctas para:

* 💧 Ahorrar la mayor cantidad de agua posible.
* 🏆 Conseguir una puntuación alta.
* 🔥 Mantener una buena racha de respuestas correctas.
* ❤️ Conservar las tres vidas disponibles.
* 🎯 Completar los 10 retos de la partida.

## 🕹️ Mecánica principal

La mecánica principal consiste en **resolver situaciones relacionadas con el ahorro de agua** mediante decisiones rápidas.

Cada situación tiene un límite de tiempo. El jugador debe leer el reto y seleccionar una respuesta.

Las buenas decisiones permiten acumular puntos y litros de agua ahorrados, mientras que una respuesta incorrecta hace perder una vida.

Además, el juego incorpora un sistema de **racha**, que recompensa al jugador por responder correctamente varias veces seguidas.

Las situaciones y la posición de las respuestas cambian entre partidas para evitar que el jugador simplemente memorice las respuestas.

## 🎨 Género

**Educativo / Arcade / Toma de decisiones**

## 🎮 Controles

**Mouse / clic:** seleccionar las respuestas y navegar por las opciones del juego.

## ❤️ Sistema de vidas

El jugador comienza con:

**3 vidas ❤️❤️❤️**

Una decisión incorrecta provoca la pérdida de una vida.

Cuando se pierden todas las vidas, la partida termina.

## 🏆 Sistema de puntuación

El juego registra diferentes elementos durante la partida:

* **Puntos**
* **Litros de agua ahorrados**
* **Racha de respuestas correctas**
* **Mejor puntuación**
* **Progreso de los retos**

La partida contiene un total de **10 retos**.

## ⏱️ Tiempo

Cada situación tiene un límite de tiempo para responder.

El jugador debe leer, analizar y decidir rápidamente para avanzar.

## 🔄 Rejugabilidad

Las situaciones y la posición de las respuestas cambian entre partidas.

Esto permite volver a jugar e intentar obtener una puntuación mayor sin depender únicamente de la memoria.

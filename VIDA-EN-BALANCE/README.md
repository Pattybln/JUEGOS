# 🌱 VIDA EN BALANCE

## 🎮 Descripción

VIDA EN BALANCE es un videojuego de exploración y simulación en el que el jugador controla un personaje dentro de un mapa.

El jugador puede desplazarse por el escenario e interactuar con diferentes opciones relacionadas con la administración de recursos y la toma de decisiones.

## 🎯 Objetivo

Explorar el mapa y tomar decisiones adecuadas para mantener un equilibrio entre los diferentes recursos disponibles durante la partida.

## 🕹️ Mecánica principal

- Movimiento libre del personaje dentro del mapa.
- Exploración de diferentes zonas del escenario.
- Interacción con diferentes elementos.
- Administración de recursos.
- Toma de decisiones.
- Seguimiento de los recursos disponibles.

## 🎨 Género

**Aventura / Simulación**

## 💻 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 🎮 Controles

| Tecla | Acción |
|---|---|
| W | Mover hacia arriba |
| A | Mover hacia la izquierda |
| S | Mover hacia abajo |
| D | Mover hacia la derecha |
| Flechas | Mover al personaje |

## 💰 Sistema de recursos

El videojuego incluye un sistema que permite al jugador observar y administrar diferentes recursos, entre ellos los ahorros disponibles.

Las decisiones tomadas durante la partida pueden modificar los recursos del jugador.

## 🗺️ Exploración

El personaje puede desplazarse por el mapa utilizando el teclado y explorar el entorno para encontrar diferentes opciones e interacciones.

## 🚀 Mejoras futuras

- Agregar más zonas al mapa.
- Incorporar nuevas interacciones.
- Agregar más decisiones.
- Mejorar las animaciones.
- Incorporar efectos de sonido.
- Añadir nuevos sistemas de recursos.
